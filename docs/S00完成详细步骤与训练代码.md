## 2. 明确S00训练范围

S00整体方法是冻结骨干提取特征，再训练受试者级分类器并在每折验证集选择融合权重。全文版只改变文本输入、重训文本分类器并重选融合；EEG与语音保持父实验输出。

```text
EEG → 已发布CBraMod-Mumtaz → 每人60×200 → EEGConvPoolClassifier → p_eeg
语音 → 冻结HuBERT → 随机冻结CNN-BiGRU编码器 → 每人29×512 → SpeechConvPoolClassifier → p_speech
按时间拼接的全部答案分段 → 冻结MacBERT CLS → 每人29×768 → LSTM1Classifier → p_text
每折val搜索权重 → p_final = wE*p_eeg + wS*p_speech + wT*p_text
```

此步骤不进行EATD迁移、不重新微调Mumtaz、不加入问题文本、跨模态注意力或动态门控。CNN-BiGRU虽含参数，但在此B0提取路径中随机初始化后冻结，不由MODMA标签训练；正式训练入口中的model是三个分类器之一。

### 9.2 全文特征提取

```powershell
Invoke-S00 -Python $MainPy -Script 'fulltext_b0.py' -ScriptArguments @('--extract')
```

实际流程：

1. 校验37人、固定划分、父实验特征及MacBERT文件哈希。
2. 逐题核对父转写与审计清单的哈希，并核对原音频哈希。
3. 验证分段时间为有限值且0≤start<end，按(start,end)排序，直接拼接原文，不插入分隔符；拒绝空结果或含错误标记的文本。
4. 独立导出全文JSON，保留来源与低音量恢复元数据，记录父转写哈希；不重新识别音频，也不改父实验转写。
5. 使用BertTokenizer计算含特殊符号的完整token数；超过512立即停止。当前最长393，无截断。
6. 冻结MacBERT推理，取last_hidden_state[:,0,:]即CLS；按29题顺序保存每人29×768的float32有限值数组。

输出：transcripts/B0-37-fulltext下1073份JSON、features/B0-37-fulltext/text下37份数组，以及该目录的features_manifest.json和protocol_resolution.json。全文特征清单只有37条文本记录，EEG/语音仍引用父实验，不能要求这里也有185条。

本次1073题中130题加入后续分段内容。全文表示“识别所得全部分段”，并不表示人工逐字校对或保证Whisper没有漏识别。超过512时需要另定长文本策略，不可自行开启截断后沿用同一协议。

## 11. 全文正式训练代码与超参数

全文入口是 `S00/scripts/fulltext_b0.py`；父实验入口 `run_b0.py`只用于依赖建立和共享输入检查。全文脚本调用upstream-dev/lib/models/models.py中的LSTM1Classifier，按种子11/22/33、每种子5折训练。

| 模态 | 分类器 | 输入 | Adamax学习率 | epoch | batch | 全文版处理 |
|---|---|---|---:|---:|---:|---|
| EEG | EEGConvPoolClassifier | B×60×200 | 0.005 | 60 | 16 | 复用父实验权重及预测 |
| 语音 | SpeechConvPoolClassifier，hidden1024 | B×29×512 | 0.005 | 70 | 8 | 复用父实验权重及预测 |
| 文本 | LSTM1Classifier，2层单向LSTM、hidden1024 | B×29×768 | 0.0001 | 50 | 64 | 新训15个分类器 |

文本dropout=0.3，weight_decay=0；每折重新设定种子，Adamax优化交叉熵。DataLoader shuffle=True、num_workers=0；每折train人数小于64，故每epoch只有一个batch。固定50轮，保存最后一轮，不依据val或test挑选epoch。推理使用eval/no_grad，softmax索引1是MDD概率。

**现有全文版已经完成，以下仅供尚无全文输出的新副本执行。** 入口没有--seed选项，一次--train依次处理三个配置种子，不要在外层再循环三次。

    """Two-layer 1-D CNN with max-pooling for pretrained EEG embeddings.

    Unlike the text ``ConvPoolClassifier``, ``seq_len`` is parameterizable
    because different EEG encoders produce different segment counts
    (CBraMod: 75, LaBraM: 30, Mumtaz: 60).
    """

    def __init__(
        self,
        input_dim: int = 200,
        seq_len: int = 75,
        num_classes: int = 2,
        dropout: float = 0.4,
    ):
        super().__init__()
        self.conv = nn.Sequential(
            nn.Conv1d(input_dim, 256, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool1d(2),
            nn.Conv1d(256, 128, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool1d(2),
        )
        conv_out_len = seq_len // 2 // 2
        self.classifier = nn.Sequential(
            nn.Flatten(),
            nn.Dropout(dropout),
            nn.Linear(128 * conv_out_len, 128),
            nn.ReLU(),
            nn.Dropout(dropout),
            nn.Linear(128, num_classes),
        )

        # x: (batch, seq_len, input_dim)
        x = x.transpose(1, 2)  # (batch, input_dim, seq_len)

class LSTM1Classifier(nn.Module):
    """Unidirectional LSTM followed by a two-layer MLP classifier.

    Takes the last time-step hidden state as the sequence representation.
    """

    def __init__(
        self,
        input_dim: int = 768,
        hidden_dim: int = 256,
        num_layers: int = 2,
        num_classes: int = 2,
        dropout: float = 0.3,
    ):
        super().__init__()
        self.lstm = nn.LSTM(
            input_size=input_dim,
            hidden_size=hidden_dim,
            num_layers=num_layers,
            batch_first=True,
            dropout=dropout if num_layers > 1 else 0.0,
            bidirectional=False,
        )
        self.classifier = nn.Sequential(
            nn.Linear(hidden_dim, 128),
            nn.ReLU(),
            nn.Dropout(dropout),
            nn.Linear(128, num_classes),
        )

    def forward(self, x):
        # x: (batch, seq_len, input_dim)
        lstm_out, _ = self.lstm(x)  # (batch, seq_len, hidden_dim)
        out = lstm_out[:, -1, :]  # last time step
        return self.classifier(out)

"""Subject-level binary metrics and validation-only weighted late fusion."""
import math

def metrics(labels, probabilities):
    if not labels or len(labels)!=len(probabilities):
        raise ValueError('Nonempty labels and probabilities must have equal length')
    if any(y not in (0,1) for y in labels):
        raise ValueError('Labels must be 0=HC, 1=MDD')
    if any(not math.isfinite(p) or not 0<=p<=1 for p in probabilities):
        raise ValueError('Probabilities must be finite and within [0,1]')
    pred=[int(p>0.5) for p in probabilities]  # softmax/argmax tie -> HC
    recalls=[]; f1s=[]
    for c in (0,1):
        tp=sum(y==c and p==c for y,p in zip(labels,pred))
        fp=sum(y!=c and p==c for y,p in zip(labels,pred))
        fn=sum(y==c and p!=c for y,p in zip(labels,pred))
        recalls.append(tp/(tp+fn) if tp+fn else None)
        f1s.append(2*tp/(2*tp+fp+fn) if 2*tp+fp+fn else 0.0)
    return {'macro_f1':sum(f1s)/2,'mdd_recall':recalls[1],
            'balanced_accuracy':sum(recalls)/2 if None not in recalls else None,
            'n_subjects':len(labels)}

def select_weights(rows):
    if not rows or any(r['split']!='val' for r in rows):
        raise ValueError('Fusion selection accepts internal validation rows only')
    if len({r['subject_id'] for r in rows})!=len(rows):
        raise ValueError('Each validation subject must appear once')
    if len({(r['seed'],r['outer_fold']) for r in rows})!=1:
        raise ValueError('Do not pool folds or seeds for fusion selection')
    best=None
    for i in range(21):
        for j in range(21-i):
            w=(i/20,j/20,(20-i-j)/20)
            p=[sum(a*r[k] for a,k in zip(w,('p_eeg','p_speech','p_text'))) for r in rows]
            score=metrics([r['label'] for r in rows],p)['macro_f1']
            if best is None or score>best['validation_macro_f1']:
                best={'weights':list(w),'validation_macro_f1':score}
    return best
```

"""CNN + Bidirectional GRU encoder with attention for audio segments.

Applies a 1-D CNN to extract local features from each segment, feeds the
result through a bidirectional GRU to capture temporal context, and
produces a single embedding via soft attention pooling.
"""

import torch
import torch.nn as nn
import torch.nn.functional as F


class BiGRUAttentionEncoder(nn.Module):
    """CNN → BiGRU → attention pooling encoder.

    Architecture:

    1. ``Conv1d(input_dim, cnn_dim) → BatchNorm1d → ReLU``
    2. ``Bidirectional GRU(cnn_dim, rnn_hidden)``
    3. Soft-attention pooling over time steps (learned linear scorer).

    Args:
        input_dim: Feature dimensionality of each input segment.
            Default 40.
        cnn_dim: Number of CNN output channels.  Default 128.
        rnn_hidden: Hidden size of each GRU direction; the final output
            has dimension ``2 * rnn_hidden``.  Default 256.
    """

    def __init__(
        self,
        input_dim: int = 40,
        cnn_dim: int = 128,
        rnn_hidden: int = 256,
    ) -> None:
        super().__init__()
        self.cnn = nn.Sequential(
            nn.Conv1d(input_dim, cnn_dim, kernel_size=3, padding=1),
            nn.BatchNorm1d(cnn_dim),
            nn.ReLU(),
        )
        self.bigru = nn.GRU(
            input_size=cnn_dim,
            hidden_size=rnn_hidden,
            num_layers=1,
            batch_first=True,
            bidirectional=True,
        )
        self.attention = nn.Linear(2 * rnn_hidden, 1)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        """Encode a batch of segment sequences into fixed-size embeddings.

        Args:
            x: Tensor of shape ``(batch, seq_len, input_dim)`` or
                ``(N_segments, input_dim)`` for a single recording.

        Returns:
            Tensor of shape ``(batch, 2 * rnn_hidden)`` — one attended
            embedding per sequence.
        """
        if x.dim() == 2:
            x = x.unsqueeze(1)            # (batch=N, 1, input_dim)

        x = x.transpose(1, 2)            # (batch, input_dim, seq_len)
        x = self.cnn(x)                  # (batch, cnn_dim, seq_len)
        x = x.transpose(1, 2)            # (batch, seq_len, cnn_dim)

        rnn_out, _ = self.bigru(x)       # (batch, seq_len, 2*rnn_hidden)

        attn_weights = torch.softmax(
            self.attention(rnn_out), dim=1
        )                                # (batch, seq_len, 1)
        attended = torch.sum(attn_weights * rnn_out, dim=1)  # (batch, 2*rnn_hidden)

        return attended
```
