## 已尝试的恢复途径

| 途径 | 实际检查 | 结果 |
|---|---|---|
| 本地压缩包重新读取 | 逐成员 CRC、SHA-256、与 raw 字节比对 | 6 份均与压缩包一致；排除了当前解压过程造成的差异 |
| WAV 格式与解码器 | Python wave 和 FFmpeg；检查 RIFF/WAVE 签名及分块字节分布 | 24–28 均失败；24–27 全文件各块的字节分布接近均匀随机，28 的前部同样异常。没有证据支持“补一个文件头即可恢复” |
| 备用 EEGLAB 包 | 枚举同一受试者成员，读取第 23 题 FDT | 24–28 不存在；23 的浮点 PCM 与损坏 WAV **逐值相等**，不是完整替代来源 |
| 公开 Kaggle 音频镜像 | 独立下载第 23–28 题、固定版本 1、计算 SHA-256 | 6 份全部与本地原始文件逐字节一致；重复下载该镜像不能修复 |
| 其他公开镜像 | 查询 Kaggle MODMA 两页、Lanzhou；核对另外两个原始数据镜像文件清单；查询 Hugging Face 和公开 GitHub 项目／问题 | 核查到的其他原始数据镜像只有 EEG，没有找到这 6 份录音的完整副本；此结论不等于证明全网不存在副本 |
| 官方来源 | 核对 MODMA 申请页及 UK Data Service ReShare 854301 | ReShare 音频入口返回 HTTP 401，需要注册访问；没有取得官方包，无法验证其录音是否完整 |

公开音频镜像：[pankajmsah/modma-audio-group-6-dsai](https://www.kaggle.com/datasets/pankajmsah/modma-audio-group-6-dsai)。它的压缩包名称及大小与本地包一致；本次进一步验证了 6 个实际成员的字节一致性。

历史证据：2021 年论文 *A Convenient and Low-Cost Model of Depression Screening and Early Warning Based on Voice Data Using for Public Mental Health* 第 2.4 节明确记载 `02010004` 语音有缺陷，并在其研究中删除了该受试者。该记载支持这是长期存在的数据源问题，但不能证明作者当年的损坏字节与本次完全相同。[原论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC8296267/)

## 波形检查补充发现

原先的“1097 份可读”仅表示 WAV 容器及 PCM 字节数检查通过，不能保证内容没有损坏。本次对全部 1097 份可解码录音做了整秒波形筛查：RMS > 0.4、绝对振幅 > 0.95 的比例 > 1%、相邻采样相关系数绝对值 < 0.05 同时成立才标记。

只有 `02010004/23.wav` 触发。其第 10 秒窗口 RMS 约 0.0062、相邻采样相关系数约 0.949；第 12–15 秒窗口 RMS 约 0.577、约 5% 样本接近满幅、相邻采样相关系数接近 0，与均匀随机噪声相符。末尾异常同时存在于 WAV 镜像和备用 FDT 中。

这是严重噪声筛查，不是所有录音的听感质量保证；不足一秒的最后一段未纳入该统计。第 28 题后半部仍有低熵字节，但缺失头部和前段无法据此恢复，未将残片当成完整题目。

当前统计：38 份 EEG；1102 份预期录音，其中 5 份不能解码、1 份严重噪声待核对、1096 份可解码且未触发本次筛查。37 位受试者各有 29 题通过这些检查，共 1073 份录音。

原始压缩包及 `dataset/modma/raw` 保留不变。第 23 题原先已复制到 staged，现将这份工作副本移入 `recovery/quarantine/staged/02010004/23.wav`，避免被后续特征程序误读；raw 原件仍在原位置。预检和完整转写仍会阻止未解决的数据进入正式 B0。

## 可执行的后续路径

1. **保留原版 38 人复现目标：** 取得有来源的 `02010004/23.wav` 至 `28.wav`，或取得 TRI-DEP 作者对这些坏文件实际处理方式的确认。官方获取入口为 [MODMA 申请页](https://modma.lzu.edu.cn/data/application/) 与 [ReShare 数据记录](https://reshare.ukdataservice.ac.uk/854301/)。MODMA 页面给出的官方音频包 MD5 为 `5550552006ec4ae5a89ecb86b7a147ac`；该值用于其对应官方包，不能直接要求重新打包的镜像 ZIP 相同。
2. **在现有数据上开展完整样本对照：** 已生成 `options/B0-37/subjects.json` 和 `fold_assignments.json`，只从每折原有集合删除 `02010004`，保留其他人的折和顺序；37 人为 16 MDD / 21 HC，五折无交叉、测试覆盖每人一次、各 train/val/test 均含两类。该方案尚未启用；它改变了人群，必须称为 **B0-37**，不能宣称精确复现论文 38 人成绩，后续方法也必须用同一批 37 人重新比较。其他 S00 模型／EEG 协议问题仍需解决。

作者发布的开发代码还包含另一条线索：语音提取 `process_recording` 在没有片段时返回零向量，转写错误则保存 `[ERROR]`。因此“代码可以继续运行”与“原始数据完整”是两回事。源码中的这两种行为不能证明论文实际采用的缺失处理政策；本次没有把错误文本编码为正常回答，也没有据此解除 B0 预检。
