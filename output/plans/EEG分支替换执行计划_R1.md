# EEG 分支替换执行计划 R1

制定日期：2026-09-25。状态：**计划已制定，尚未修改模型或启动训练。**

目标：提高 MODMA-37 上真正 EEG 单模态的受试者级 Macro-F1，并检验替换后的 EEG 分支能否用于完整 CCML。新实验使用独立的 `EEG-R1` 名称，已收尾的 CCML-v2 结果继续保留。

## 1. 执行顺序与范围

**先核验数据和接口，再做小型 EEGNet，随后做 SparNet-inspired，最后做 CBraMod+MHAP。** 首轮只用一个预先指定的 EEGNet 配置，不做大规模调参。

设两条评价线，分别报告：

- **U 线：EEG 独立训练。** 只输入 EEG、只用 EEG 的交叉熵监督；回答“EEG 单模态是否变好”。
- **C 线：完整 CCML 联合训练。** 固定语音、文本输入及其分支结构，替换 EEG 编码器；同时报告 EEG 分支输出和最终融合。C 线的 EEG 输出受联合训练影响，不能当作 U 线成绩。

独立 CE 线是本次 EEG 修改的诊断协议，不改写 v2 的 CCML-only 实验。C 线继续保留完整 CCML，不增添最终融合监督、动态门控或证据尺度搜索。

首轮预算为 **4 个条件 × 3 种子 × 5 折 = 60 组训练**，包含两个重新训练的直接对照。后续固定候选再增加 60 组，完整上限 **120 组**；可按阶段分批执行。只有数据完整性、实现正确性和资源检查决定阶段能否开始，不能看外层测试成绩再增删候选。

现有人群已被多次用于开发。这次固定比较能提高归因与复现质量，不能让这 37 人重新变成独立验证集。

## 3. 阶段 0：准备数据与独立运行入口

### 3.1 新增原始 EEG 派生缓存

现有 `(60,200)` 是 CBraMod 平均后的特征，不能输入 EEGNet，也不能恢复电极信息。复用已有 staged MAT、已修订的标签选择及预处理，新增每人 `(60,19,1000)` 的 float32 缓存：

`原始 MAT → 按实际 E 标签选 19 导 → 250 Hz 重采样至 200 Hz → 0.3–75 Hz 滤波及 50 Hz 陷波 → 前 300 秒 → 60 个不重叠 5 秒窗`

复用 [extract_eeg.py](<C:/Users/jin  qiyan/Desktop/lunwen2/tridep_ccml/v2/extract_eeg.py:19>) 中已核查的计算顺序；其 `(60,19,5,200)` 返回值可在每导内部展平为 `(60,19,1000)`。不重新下载数据，不重新转换 FDT，不修改原始文件。37 人缓存约 169 MB（十进制，不含清单）。

原始派生缓存保持 native 数值。EEGNet/SparNet 的输入在各训练折内另作每导标准化：对训练人的全部等长窗口估计均值和标准差，固定用于该折 val/test；记录统计量、来源人及哈希。近零方差通道触发输入检查，不用测试成绩选择缩放倍数。此标准化属于明确登记的新输入处理，不能将整体增益全部归给网络结构。

冻结 CBraMod 路线继续使用旧输入尺度，不将上述新标准化送入冻结骨干。Mumtaz 输入尺度来源尚未闭环，是该路线的限制，不阻塞从头训练的 EEGNet；禁止据测试 F1 反推单位。

### 3.3 进入正式训练前的验收

1. 37 人名单、标签、折与来源哈希一致；所有窗口随所属受试者划分。
2. 新窗口展平后能重建既有预处理输出；形状、有限值与幅值统计通过。
3. 小批前向与反向通过，EEG 表示为 `(B,128)`；C 线三路顺序为 EEG/语音/文本，证据为 `(B,3,2)`。
4. EEGNet 的 BatchNorm/Dropout 使用正常 `train()`，推理 `eval()`；冻结骨干始终 `eval()`。旧代码中为关闭 Dropout 而全模型 `.eval()` 的做法不能直接复制到 EEGNet。
5. BatchNorm 只用训练数据更新；推理不更新参数或统计，不受测试批次组成影响。
6. 训练规定模块确有有限梯度；共享语音/文本初始权重与批次顺序配对。不能只设同一个 seed 就假定新增 EEG 层后其他分支初始化仍相同。
7. 先测量单批显存和单轮时间，再估计全部耗时。默认单 GPU、float32、确定性模式，不开混合精度；若需 CPU，整组配对条件使用一致环境并在正式训练前登记。

检查只验证工程正确性，不用外层成绩决定实现。若内存不足，不悄悄减少每人的窗口；分块方案要先验证梯度及 BatchNorm 行为，必要时更新配置再开始整组训练。

## 4. 阶段 1：EEGNet 首轮，60 组

### 4.1 明确的四个条件

| ID | 训练方式 | EEG 路径 | 直接比较 |
|---|---|---|---|
| U0 | EEG-only CE | 修订 CBraMod `(60,200)` + 原 EEGConvPoolClassifier | U 线重新训练的控制 |
| U1 | EEG-only CE | 原始 19 导 + EEGNet + 受试者均值 | U1 对 U0 |
| C0 | 完整 CCML | S-control 的 CBraMod 时间均值 + 200→128 投影 | C 线重新训练的控制 |
| C1 | 完整 CCML | 原始 19 导 + EEGNet + 受试者均值 + 128 维接口 | C1 对 C0 |

U0 重新训练是因为本轮统一了优化和批大小；其成绩不能直接写成历史修订 EEG 的 0.411825。C0 同样重新训练，使运行环境和新入口有直接配对依据。历史原 EEG 0.449401、修订 EEG 0.411825、S-control 融合 0.790859 仅作来源明确的历史参照，不作为新条件的预设成绩。

### 4.2 首轮 EEGNet 规格

- 固定小配置 `F1=4, D=2, F2=8`；时域卷积、深度空间卷积、可分离卷积。
- 输入每窗为 `19×1000`；时域核 100 点，对应 200 Hz 下的 0.5 秒；可分离时域核 25 点位于第一次池化后，对应 50 Hz 特征轴上的 0.5 秒跨度（不是整个网络的总感受野）。使用保持长度的 padding；平均池化因子 4、8；ELU；Dropout 0.25。
- 预期每窗末端为 `8×1×31`，展平为 248 维；对同一人的 60 窗等权均值，再 `Linear(248,128)→ReLU`。
- U1 接 `Linear(128,2)` logits 后计算受试者级 CE。C1 在 128 维后接 S-control 相同的无仿射 LayerNorm 和证据头。
- 深度空间卷积使用最大范数 1，U1 的末端 CE 二分类层使用最大范数 0.25；在优化更新后执行并记录。C1 的证据头不加这项范数约束，与 C0 的证据头政策一致。其余卷积不额外增加范数约束。
- U1/C1 都从随机初始化训练 EEGNet；不加载旧 CNN 或旧 MODMA 监督模型权重。两线共享编码器结构但分别训练。
- 该设计含本项目的受试者聚合与 128 维接口，称为 EEGNet 改造分支，不声称逐项复现原 BCI 实验。EEG 侧参数预算不超过 5 万，实际数量由实现计算；不能引用论文其他输入配置的参数数目。

如实现形状与预期不同，先检查卷积/池化及轴顺序，在正式训练前修正；不得看外层 F1 后再改宽度。

### 4.3 优化与训练范围

| 项目 | U0 / U1 | C0 / C1 |
|---|---|---|
| 损失 | 标准受试者级 CE | 完整 CCML，rho=1.25、delta=gamma=1、KL 退火 50 轮 |
| 优化器 | Adamax | Adamax |
| 学习率 | 全部可训练参数 1e-3 | 编码器及投影 1e-4；三路证据头 1e-3 |
| weight decay | 1e-4，作用范围固定并记录 | 0，沿用 S-control |
| 训练 | 60 轮、batch=8 人、不 drop_last | 同左 |
| 梯度裁剪 | 全部可训练参数总范数上限 1 | 同左 |
| 可训练范围 | EEG 编码/分类模块 | 新 EEG 编码器、三路投影与三路证据头 |
| 骨干 | U0 的 CBraMod 冻结 | C0 的 CBraMod、两条件的 HuBERT/MacBERT 均冻结 |

U0 保持原 CNN 结构和 Dropout 0.4；U1 使用上述 EEGNet 内部 Dropout。两者输入表征、网络及结构内正则不同，比较结论是“EEG 分支整体替换是否有效”，不是只改一个卷积模块的因果结论。

C0/C1 的语音输入均为 AS 完整覆盖后的 29 题 HuBERT 等权均值，文本均为全文 MacBERT 29 题 CLS 均值，都是 768 维；各自 768→128 投影、无仿射 LayerNorm、证据头完全同构且同初始化。其投影和头在两条件中都训练，因此 EEG 改变后语音/文本概率可能变化；不能承诺其他两路概率不变。

每组固定 60×ceil(train人数/8)=240 次更新。首轮 60 组共 **14,400 次更新**。配置锁定后不添加类别重采样、增强、额外辅助损失或早停。

## 5. 阶段 2：SparNet-inspired，新增 30 组

固定新增 U2、C2 两个条件，各 15 组，分别对 U0、C0，也完整展示与 U1/C1 的差值。

共享阶段 0 的 19 导、5 秒窗口、折内标准化及受试者均值汇聚，使用频谱输入、五脑区并行卷积和 SE 权重。依据已下载原文的层表实现，但按 19 导重新设置输入维度，命名 `SparNet-inspired-19ch`；不照搬原 73 导，也不引用原 8,725 参数作为本地参数量。

实施时先形成独立的结构清单：频谱计算及尺度、频率范围、卷积宽度、区域映射、SE 缩减率、实际参数量。该清单只根据论文和输入形状确定，在 U2/C2 训练前锁定，不根据第一阶段外层成绩调整。

脑区必须从实际 19 个标签核对：当前包含 FCz、CPz，不能假设有 Fz、Cz，不能把一般 10–20 通道顺序直接套到数组。厂家近似对应及坐标限制须写入映射清单；若区域来源不能核实，暂停此阶段，保留已完成的 EEGNet 结果。

继续沿用 U/C 两线各自的优化规则、完整 CCML 接口及汇聚方式。原论文中的其他去噪、不同窗口长度、导联扩展不同时加入本轮。新增 **7,200 次更新**。

## 6. 阶段 3：预训练 token 聚合，新增 30 组

固定新增 C3、C4，只做完整 CCML 的成对聚合实验，均保留 C0 的语音、文本路线。

- 重新从冻结 CBraMod 导出每人的 `(60,19,5,200)` token，保持原 native 预处理。37 人约 169 MB float32，与原始窗口两份合计约 337 MB，不含清单；不能从旧 `(60,200)` 反推。
- 必須验证 token 在通道与 1 秒位置上平均后重现已有修订缓存，容差预先固定 `rtol=1e-4, atol=1e-4`。失败先查骨干、数值模式或输入来源。
- 两条件共享 `200→32` 的 token 投影、受试者级 60 窗均值、`32→128` 接口与初始化。
- **C3：**每个 5 秒窗的 95 个 token 做均值聚合。
- **C4：**每窗使用 2 头可学习查询的注意力聚合，输出与均值以固定 0.5/0.5 残差合并；不搜索残差系数。
- 两条件均不增加 Transformer、8 层 CC-GMLP 或新的预训练骨干。注意力轴、共享投影、实际残差公式和参数量在训练前登记。

C4 的直接对照是 C3，不直接拿 C4 对 C0 的变化解释注意力效果。称为 `CBraMod+MHAP / STAMP-inspired`，不称完整 STAMP 复现。该阶段没有 EEG-only CE 新实验，故其 EEG 输出只属于 C 线。新增 **7,200 次更新**。

## 7. 通过标准、失败处理与资源上限

下述门槛是预定的开发决策标准，不是统计显著或临床有效标准。

| 判断 | 要求 |
|---|---|
| U 线 EEG 有改善 | 对同协议 U0，主 Macro-F1 增加至少 0.03；至少 2/3 种子的五折均值严格提高；MDD recall 降幅不超过 0.05 |
| C 线 EEG 有改善 | 对各自直接控制，EEG 分支满足相同的 F1 与召回要求 |
| 可接入完整 CCML | 同时检查 C 线融合：主 Macro-F1 降幅不超过 0.01，MDD recall 降幅不超过 0.05；披露 NLL/Brier 的方向与幅度 |
| 仍不可用的情况 | 即使 ΔF1 达标，若 BA≤0.5、MDD recall<0.5 或预测塌缩到单类，仍标为尚不具备可用性，不宣称问题已解决 |

结果解释分开：U 提高而 C 未提高，说明独立编码有效但联合训练/融合仍需研究；C 提高而 U 不提高，只支持联合条件下的收益；只降低训练 F1 不算提高泛化。

每条件输出逐人 p/标签/证据、逐折及逐种子指标、合并 OOF、训练—测试差距和分类改变。报告 BA、MDD recall、NLL/Brier，保留原主统计口径；如计算配对 bootstrap，按原始 subject_id 成组保留三个种子及候选/控制预测，不能把 111 行当成 111 人。

所有候选按预定预算与工程验收顺序执行；外层结果用于事后评价，不决定临时搜索。若要从多种结构中自动选择一个模型，另设训练人群内部选择程序或使用新独立队列，不能把本轮外层最高分当作无偏的选模后成绩。

**暂停条件：**来源或划分不一致、非有限损失、BN 使用测试信息、应冻结模块被更新、参数量超预算、无法按既定资源执行、检查点不能复现。暂停时定位并记录问题，修复后重新跑受影响的完整配对组；不靠删人、删坏折或改测试阈值绕过。
