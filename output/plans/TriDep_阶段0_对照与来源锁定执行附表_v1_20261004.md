# TriDep 阶段0：对照与来源锁定执行附表

登记日期：2026-10-04。对应[汇总计划 v1](TriDep_EEG与融合改进及语音文本泛化汇总计划_v1_20261004.md)第0阶段。本附表在本阶段重放及新增ST控制评价前保存。

## 范围与预算

以 `S00/configs/b0_fulltext.json` 的 B0-37-fulltext 为唯一直接父版本。37人、16 MDD/21 HC、原五折、种子11/22/33保持不变。新增神经训练、内层训练、校准、优化器更新均为0；重载45个原检查点，15组逐人推理，每组37人×3模态，共1665次分支前向。另做缓存接口回放及重复输入不变性核验，不计为拟合。

| 对象 | 固定来源或规则 |
|---|---|
| S权重 | `S00/runs/B0-37/seed_<seed>/fold_<fold>_speech.pt`，原70轮最终状态 |
| T权重 | `S00/runs/B0-37-fulltext/seed_<seed>/fold_<fold>_text.pt`，全文版50轮最终状态 |
| E权重 | `S00/runs/B0-37/seed_<seed>/fold_<fold>_eeg.pt`，原60轮最终状态 |
| S输入 | `S00/features/B0-37/speech/seed_<seed>/<subject>.npy`，29×512 |
| T输入 | `S00/features/B0-37-fulltext/text/<subject>.npy`，29×768 |
| E输入 | `S00/features/B0-37/eeg/<subject>.npy`，60×200；本阶段不替换为E2v2 |
| 表示出口 | 原分支最后二分类Linear的输入，eval下128维，位于原末端投影和ReLU之后；每折所有37人均有缓存 |
| 历史表示核对 | 与 `tridep_ccml/features/seed_<seed>/fold_<fold>.npz` 的原TC准备缓存逐位核对，核对其元数据与父权重、输入和代码哈希 |
| 原EST主控制 | 直接复用原B0-37-fulltext val选择的三模态权重；重放原0.05网格与字典序平局规则，不重新优化 |
| 固定ST主控制 | 原概率融合规则限制E权重为0，S权重依次0、0.05、…、1，T权重为1−S；仅用本折原3人val Macro-F1选择，严格改善才更新，平局保留较低S权重。共21×15=315个确定性候选评分，15次选择，0次模型拟合 |
| 补充控制 | ST概率等权与EST概率等权，事前固定，不根据test成绩选择主控制 |
| 推理固定 | 原class及全部原state_dict严格加载；eval、requires_grad=False、inference_mode；核对参数及buffer推理前后逐位相同 |

本阶段新登记的ST控制是原S/T来源上的确定性重算，不伪称此前已有独立ST实验。历史EST的231×15=3465个val网格评分只用于来源复算，不新增选择。若发现来源不齐、哈希或输出不符，停止该项并保存失败记录，不能引入后期G1、M2、CCML或改过题级汇聚的S/T替代。

## 来源锁定与验收

核对并保存：活动/原38人分折、37人名单、诊断工作簿、原raw音频与EEG、staged音频与EEG、原ASR及全文转写、输入特征与producer、HuBERT/MacBERT/Whisper/CBraMod资产、随机冻结语音编码器、原E/S/T检查点、配置、代码、历史预测与原TC缓存的SHA-256。只读原文件；新增产物放在 `output/analysis/tridep_stage0_20261004`。

输出包含逐seed/fold来源表、分折与训练人员清单、15份含E/S/T 128维表示和概率的缓存及元数据、555条分支概率、四个控制各555条train/val/test预测、测试逐人ST→EST变化、完整指标和机器可读完成状态。主指标为每种子五折均值再取三种子均值，另列每种子37人OOF合并指标；111条测试记录只代表37人的三个种子重复观察。阈值p>0.5为MDD、相等为HC。

验收要求：45个检查点来源与本折train人员完全一致；1665个分支概率重放误差≤1e-6，分类不变；15份原128维表示逐位一致；参数与buffer未更新；各控制每种子37人测试恰好一次；原EST预测和主F1与历史一致；原来源文件前后哈希一致。NLL使用1e-15截断，Brier为二分类MDD概率平方误差，AUC按正负成对排名并以0.5处理平分。

## 评价边界与下一阶段入口

原每折3人val未进入本折S/T监督训练，但已用于历史融合选择；其人数极少，不作为新的独立验证。若将本折train再次切为内层train/val，固定S/T已经训练过这些内层val人员，不能将缓存称为合法内层OOF。阶段1/3须另行登记固定参数与预算；阶段0通过不自动启动候选训练。

原S00语音包含随机冻结编码器、退化注意力与短音频空特征；原EEG幅值/通道来源限制继续披露。阶段0锁定其原样来源，不据此宣称修复了这些问题。当前37人均属反复使用的开发人群；不能由本阶段重算分数得到新的跨域或独立人群证据。
