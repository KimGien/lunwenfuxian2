# EEG-P1 复核入口

本目录实现原因分析的后续优先级 1：有效学习检查和 SparNet 退化修复。使用原 R1 输入，不使用 EEG 数据增强。

运行入口：在项目根目录使用现有 S00/.venv/Scripts/python.exe 执行 `-m tridep_ccml.eeg_p1.run`。

首次运行依次执行训练集工程验收、配置冻结、60 组正式训练、全量训练探针重载、外层评价与报告。已有完整交付时仅核验冻结文件；已冻结但未完成的运行会复核配置和已完成检查点，再继续缺失项。工程验收失败会停止，不自动降低门槛，不按外层成绩搜索。

- `health.py`：逐编码模块任务梯度、跨受试者表示方差、输入/脑区敏感性；检查前后恢复模型、模式、梯度和随机状态。
- `prepare.py`：原 C2 退化检查点负例、四人训练子集拟合和预检配置。
- `test_contracts.py`：身份隔离、初始化配对、负例拒绝、非有限表示拒绝、探针恢复等回归测试。
- `models.py`：固定 FFT 数值尺度、4 路区域/全局卷积、LeakyReLU 与匹配初始化。
- `train.py`：固定 60 轮，逐轮模块梯度和权重更新，原控制确定性重放。
- `evaluate.py`：先重载全部 60 组训练探针，再统一外层推理；独立概率和指标复算。
- `finalize.py`：原协议配对判定、修复前后描述、曲线和冻结文件核验。

产物：`tridep_ccml/experiments/EEG-P1-37-fulltext/EEG-P1执行报告.md`。
预登记：`output/plans/EEG_P1有效学习验收与SparNet修复固定计划.md`。

U2/C2 在新目录表示 U2-P1/C2-P1；原 R1 的同名条件仍指旧实现。正式训练使用的模型从头初始化，四人拟合模型不会用于预训练或选轮。现有 37 人结果是开发比较，工程验收通过与泛化性能提高分别报告。
