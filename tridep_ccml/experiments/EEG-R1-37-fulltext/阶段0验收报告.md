- 原人群 37 人，16 MDD/21 HC；原五折、种子 11/22/33；每个受试者全部窗口始终属于同一划分。
- 每人原始派生缓存 60×19×1000，原始数值保留；37/37 展平重建精确一致。
- 每人冻结 CBraMod token 为 60×19×5×200，37/37 均值复现通过，最大绝对差 0，容差 rtol=atol=1e-4。
- EEGNet/SparNet 各折标准化仅由训练人的全部等长窗口估计，五份统计独立保存；CBraMod 保持 native 尺度。
- 训练 batch=8 人，完整 60 窗；无窗口丢弃，无微批次；无类别重采样。
- 接口为每人 128 维，C 线证据为 B×3×2，顺序 EEG/语音/文本。BN/Dropout 训练时启用，推理不更新统计；梯度、参数均有限。
- C 条件语音/文本投影及全部证据头初始化逐项一致；C3/C4 的共享 token 投影与接口相同。
- SparNet 标签/五脑区、FFT 范围和尺度、SE、卷积，以及 token 注意力公式已在任何外层分数释放前冻结，见 structure_manifest.json。
