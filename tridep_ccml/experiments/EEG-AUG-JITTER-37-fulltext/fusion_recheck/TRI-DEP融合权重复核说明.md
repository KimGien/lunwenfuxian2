# TRI-DEP 融合权重复核与表述更正

复核日期：2026-09-27。用户指出论文中的 EEG 权重并非 0。**该指正成立：论文表 4 的三模态加权平均使用 EEG／语音／文本 = 0.05／0.35／0.60。** 此前“15 折 EEG 权重为 0”描述的是本地 37 人实验的逐折选权结果，不能作为论文设置或 EEG 无贡献的证据。此前将该融合结果直接称为“原 TRI-DEP”，没有充分区分协议差异，现予以更正。

## 论文、作者代码快照与本地协议

| 项目 | 核对结果 |
|---|---|
| 论文三模态 Weighted Averaging | EEG 0.05、Speech 0.35、Text 0.60；表 4 报告 Macro-F1 0.864 ± 0.095 |
| 作者发布代码的三模态搜索空间 | `weight_vals` 从 0.05 开始；三模态权重均不得低于 0.05；因此此搜索空间不会产生 EEG=0 |
| 本地逐折选权 | 在当折 3 人验证集上搜索，允许 EEG、语音或文本为 0，网格步长 0.05 |
| 本地并列规则 | 按 EEG 权重升序、再按语音权重升序遍历；只有 F1 严格更高才更新，因此并列时保留较小 EEG 权重 |
| 本地配置中的论文权重 | 已记录 `paper_reference_weights=[0.05,0.35,0.60]`，但仅作参考，原主融合计算未使用它 |

论文来源：[arXiv v2 表 4](https://arxiv.org/html/2510.14922v2#S4.T4)。代码来源为工作区保存的作者 dev 快照 `S00/upstream-dev/scripts/fusion_grid_search.py`（第 146–160 行）及 `configs/training/fusion.yaml`。本地执行来源为 `S00/scripts/metrics.py`（第 23–37 行）、`S00/configs/b0_fulltext.json` 和 `tridep_ccml/tc00_eeg.py` 的 `fuse`。

作者发布脚本的 `eval_config` 使用固定各折 test IDs 汇总搜索分数；本地另行固定了只用各折 val 选权的方案。这里描述可查代码差异，不据此推断作者所有实验操作或把本地协议称为精确论文复现。

## 0 权重是否意味着 EEG 被验证为无用

重新枚举每折全部 231 个本地候选组合，并从原始逐人概率复算验证 Macro-F1，精确重现了已保存的选权结果：

| 核查项 | 修订导联、无增强 | 修订导联、有增强 |
|---|---:|---:|
| 最终选中 EEG=0 的运行 | 14/15 | 15/15 |
| 存在 EEG>0 且同样达到最优验证 F1 的运行 | 15/15 | 14/15 |
| 存在三个模态均 ≥0.05 且同样达到最优验证 F1 的运行 | 13/15 | 14/15 |
| 每折并列最优组合数范围 | 3–158 | 1–158 |

因此，增强组有 14/15 折的零 EEG 权重并非唯一最优解。大量并列解与本地升序保留规则共同影响了最终权重。不能把“被选为 0”解释成模型已经证明 EEG 无效；这也不是可训练门控学出来的权重。

## 按论文固定权重补算

使用同一批已完成的三分支预测，直接计算：

`P(MDD) = 0.05 × P_EEG + 0.35 × P_speech + 0.60 × P_text`。

没有重新训练、没有搜索新权重，也没有用测试结果挑选权重。该补算是发现协议差异后的事后核查，不能称为预先登记的新验证实验。分数仍采用每种子五折均值、再三种子平均。

| 融合协议 | 无增强 Macro-F1 | 增强 Macro-F1 | 差值 |
|---|---:|---:|---:|
| 本地每折验证集选权，允许零权重 | 0.724180 | 0.724180 | 0.000000 |
| 论文固定加权平均 0.05／0.35／0.60 | 0.717037 | 0.725503 | +0.008466 |

| 固定论文权重的种子结果 | 无增强 | 增强 |
|---|---:|---:|
| 11 | 0.734603 | 0.760000 |
| 22 | 0.678889 | 0.678889 |
| 33 | 0.737619 | 0.737619 |

在 111 条重复种子外层测试记录中，1 条由错变对、0 条由对变错；MDD recall 从 0.600000 变为 0.616667，BA 从 0.721667 变为 0.730000，NLL 从 0.582301 变为 0.577827，Brier 从 0.187752 变为 0.187225。只有种子 11 的硬分类改变，独立受试者仍是 37 人。

更正后的解释是：**论文权重下，增强带来小幅融合改善；本地允许零权重的逐折选权融合 F1 未变。** EEG 独立分支 Macro-F1 仍是 0.411825 → 0.392629，不受后端融合权重影响；不能以融合小幅改善宣称 EEG 独立分类得到提升。固定论文权重的改善不足 0.01，且未在至少两个种子上改善，尚不构成稳定收益。

此次补算仅对齐融合公式及固定权重；37 人数据、三种子、分支训练和预处理仍是本地版本，**不是**论文 38 人结果的精确复现。

逐折选权并列解统计及完整指标见 `recheck.json`；固定论文权重的 555 条逐人预测见 `paper_weight_predictions.json`。核查入口为 `tridep_ccml/eeg_aug/recheck_fusion.py`。原训练配置、历史检查点、预测文件及本地选权代码均保留，核查结果单独存放。
